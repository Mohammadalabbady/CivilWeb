3. BILINGUAL SUPPORT (ARABIC/ENGLISH)
================================================================================

The application supports both Arabic and English languages with full RTL/LTR
layout switching.

-----------------------------------------------------------------------------
3.1 How Language Switching Works
-----------------------------------------------------------------------------

1. User clicks language button (EN or ع) in the navbar
2. Request goes to: /Language/Change?lang=ar (or lang=en)
3. LanguageController sets a cookie named "Language" with value "ar" or "en"
4. Cookie expires in 1 year
5. User is redirected back to the previous page
6. All views read the cookie and render content in the selected language

-----------------------------------------------------------------------------
3.2 LanguageController.cs
-----------------------------------------------------------------------------

File: Controllers/LanguageController.cs

Code:
    public class LanguageController : Controller
    {
        [HttpGet]
        [Route("Language/Change")]
        public IActionResult Change(string lang, string returnUrl = "/")
        {
            Response.Cookies.Append("Language", lang, new CookieOptions
            {
                Expires = DateTimeOffset.UtcNow.AddYears(1),
                IsEssential = true
            });

            if (!string.IsNullOrEmpty(returnUrl) && Url.IsLocalUrl(returnUrl))
                return Redirect(returnUrl);

            return RedirectToAction("Index", "Home");
        }
    }

-----------------------------------------------------------------------------
3.3 View Language Pattern
-----------------------------------------------------------------------------

Every view uses this pattern at the top:

    @{
        var lang = Context.Request.Cookies["Language"] ?? "ar";
        var isArabic = lang == "ar";
        ViewData["Title"] = isArabic ? "العنوان بالعربي" : "English Title";
    }

For text content:
    @(isArabic ? "نص عربي" : "English text")

For icon positioning (margin):
    <i class="fas fa-icon @(isArabic ? "ms-2" : "me-2")"></i>

For back arrow direction:
    <i class="fas @(isArabic ? "fa-arrow-right" : "fa-arrow-left")"></i>

-----------------------------------------------------------------------------
3.4 Layout RTL/LTR Support
-----------------------------------------------------------------------------

File: Views/Shared/_Layout.cshtml

The layout dynamically switches between RTL and LTR:

    @{
        var lang = Context.Request.Cookies["Language"] ?? "ar";
        var isArabic = lang == "ar";
        var dir = isArabic ? "rtl" : "ltr";
        var langCode = isArabic ? "ar" : "en";
    }
    <html lang="@langCode" dir="@dir">

For Arabic:
- Uses Bootstrap RTL CSS (bootstrap.rtl.min.css)
- Uses Cairo font (Google Fonts)
- HTML dir="rtl"

For English:
- Uses Bootstrap LTR CSS (bootstrap.min.css)
- Uses Inter font (Google Fonts)
- HTML dir="ltr"

HOW TO MODIFY GENDER COUNT:
Location: HomeController.cs, Lines 22-23

Male count query checks for:
- "Male" (English)
- "ذكر" (Arabic with space)
- "ذكر " (Arabic without space)
- Trimmed version of "ذكر"

Female count query checks for:
- "Female" (English)
- "أنثى" (Arabic with hamza)
- "انثى" (Arabic without hamza)
- "انثي" (Arabic with yaa)
- "أنثي" (Arabic with hamza and yaa)
- Any value containing "نث"

TO ADD NEW GENDER VALUES:
Add to the CountAsync query condition:
c.Gender == "YOUR_VALUE" ||

6.2 CivilController.cs (Controllers/CivilController.cs)
-----------------------------------------------------------------------------

Purpose: CRUD operations for civil records

Actions:
+------------------+--------+------------------------------------------------+
| Action           | Method | Description                                    |
+------------------+--------+------------------------------------------------+
| Index            | GET    | List records with search, sort, pagination     |
| Details/{id}     | GET    | View single record details                     |
| Create           | GET    | Show create form                               |
| Create           | POST   | Save new record                                |
| Edit/{id}        | GET    | Show edit form                                 |
| Edit/{id}        | POST   | Update existing record                         |
| Delete/{id}      | GET    | Show delete confirmation                       |
| DeleteConfirmed  | POST   | Delete record from database                    |
| Export           | GET    | Export records to Excel file                   |
| Search           | GET    | AJAX API for live search (returns JSON)        |
+------------------+--------+------------------------------------------------+

SEARCH LOGIC (Lines 19-127):
1. If searchId is provided -> Find person by ID, get their RegistrationNumber
2. If searchName is provided -> Find person by name, get their RegistrationNumber
3. If RegistrationNumber found -> Return ALL family members with same registration
4. If no RegistrationNumber -> Return only matching records

SORTING OPTIONS:
- id, id_desc
- firstname, firstname_desc
- secondname, secondname_desc
- thirdname, thirdname_desc
- lastname, lastname_desc
- fullname, fullname_desc
- gender, gender_desc
- birthdate, birthdate_desc
- alive, alive_desc

EXCEL EXPORT (Lines 248-348):
- Uses ClosedXML library
- Exports with headers: ID, First Name, Second Name, Third Name, Last Name,
  Full Name, Registration Number, Birth Date, Gender, Alive
- Maximum rows: 1,048,575 (Excel limit)

-----------------------------------------------------------------------------
8.1 Add a New Field to CivilDatum
-----------------------------------------------------------------------------

Step 1: Add property to Models/CivilDatum.cs
    public string? NewField { get; set; }

Step 2: Add column configuration in Data/ApplicationDbContext.cs (OnModelCreating)
    entity.Property(e => e.NewField).HasMaxLength(50);

Step 3: Update Views to display the new field (add bilingual support)
    - Views/Civil/Index.cshtml
    - Views/Civil/Details.cshtml
    - Views/Civil/Create.cshtml
    - Views/Civil/Edit.cshtml

Step 4: Update CivilController.cs
    - Add to [Bind] attributes in Create and Edit actions
    - Add to Export columns if needed
    - Add to Search JSON response if needed

Step 5: Run database migration or update database schema

11. TROUBLESHOOTING
================================================================================

Problem: Language not switching
Solution:
1. Check if LanguageController is compiled (dotnet build)
2. Verify cookie is being set (browser dev tools -> Application -> Cookies)
3. Check URL is correct: /Language/Change?lang=ar

Problem: RTL layout not working
Solution:
1. Check html tag has dir="rtl" attribute
2. Verify Bootstrap RTL CSS is loading for Arabic
3. Clear browser cache

Problem: Female count shows 0
Solution: Check what gender values exist in database:
    SELECT DISTINCT Gender, COUNT(*) FROM CivilData GROUP BY Gender
Then add matching values to HomeController.cs Line 23

Problem: Search not working
Solution:
1. Check browser console for JavaScript errors
2. Verify /Civil/Search endpoint returns data
3. Check database connection in appsettings.json

Problem: Excel export fails
Solution:
1. Check if ClosedXML package is installed
2. Verify data doesn't exceed 1,048,575 rows
3. Check server memory for large exports

Problem: Page loads slowly
Solution:
1. Run CreateIndexes.sql to add database indexes
2. Reduce default page size
3. Add AsNoTracking() to read-only queries

Problem: Arabic text truncated in database
Solution: Column sizes may be too small. Run:
    ALTER TABLE CivilData ALTER COLUMN FirstName NVARCHAR(50);
    ALTER TABLE CivilData ALTER COLUMN LastName NVARCHAR(50);
    ALTER TABLE CivilData ALTER COLUMN FullName NVARCHAR(200);
